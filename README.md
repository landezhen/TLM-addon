# 女仆挖矿附属 (Maid Mining Addon)

给「车万女仆」(Touhou Little Maid) 加两个任务：矿物采集和方块采集。基于 Forge 1.20.1，零 Mixin 实现。

## 功能

矿物采集

- 十类矿物独立勾选（煤、铁、铜、金、红石、青金石、钻石、绿宝石、下界矿物、远古残骸）
- 穿透视野：可让女仆透过石头找矿，穿透距离 1-8 可调
- 连锁挖矿：挖一块带走整条矿脉，上限可调
- 镐子等级检测：可选是否只用正确工具，关掉她真会拿木镐砸钻石
- 废石处理：按白名单丢弃多余或全部废石，保留数量可设
- 自动搭路：遇沟填坑，不会掉进岩浆
- 锚点可视化：X 光线框显示范围内的矿，需在客户端配置里开启

方块采集

- 最多三个目标方块，可设采集数量上限

## 构建

依赖两个不在仓库里的 jar，因为它们是别人的作品。自行下载后放进 `libs/` 目录：

| 文件名 | 说明 |
| --- | --- |
| `touhoulittlemaid-1.20.1-all.jar` | 车万女仆 1.20.1 的 dev/userdev 构件 |
| `maid_useful_task-1.4.2.jar` | 女仆使用任务 1.4.2 |

车万女仆要的是 dev 构件（带 `-all` 后缀那个），不是玩家版 jar。玩家版是混淆过的，编译期用不了。

然后执行 `./gradlew build`，产物在 `build/libs/`。

## 运行依赖

- Minecraft 1.20.1
- Forge 47 以上
- Touhou Little Maid 1.5.0 以上
- Maid Useful Task 1.4.0 以上（硬依赖，缺了进不了游戏）

## 代码结构

- `task/` 两个任务的主逻辑与目标搜索
- `behavior/` 行为节点：移动、连锁、搭路、丢废石、超时兜底
- `client/` X 光扫描与线框渲染
- `config/` 配置数据与读写
- `menu/` 配置界面
- `network/` 数据包与同步
- `util/` 矿物匹配、连锁管理、配色

## 移动端说明

在 ZL2 启动器加 Mobile Glues 渲染器上开发和测试。全程不用 Mixin 和 VBO，可视化走即时模式渲染，对转译层友好。
